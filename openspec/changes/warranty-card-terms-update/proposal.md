# 提案：保修卡换新条款、去掉成色

## 为什么（Why）

保修卡是给买家的凭证，上面印的三条旧条款（非人为故障保修／私拆即失效／凭序列号保修）是早期简版，店主现在有了正式的四部分条款文本（保修范围、免责条款、售后须知、店铺承诺 + 温馨提示），旧条款已经不够用，也容易被买家挑字眼。另外卡面上的「成色」是店主内部口径，印在给买家的凭证上没有意义。

## 改什么（What Changes）

- 卡面**去掉「成色」一行**（`_kv('成色', ...)` 删除），其余商品信息（标题、型号、序列号）不动。
- 卡面条款区**换成店主给的四部分完整文本**，逐字照抄，含「一、保修保障范围」「二、不在保修范围（免责条款）」「三、售后服务须知」「四、店铺服务承诺」四组小标题与结尾的「温馨提示」。
- 为装下这 540 字（18 段），条款区**字号 8.5 → 7.5、行距 1.32、段间距收紧**，同时压缩卡面上方的空档（标题限 1 行、kv 间距、商家保修框内边距），**卡面尺寸仍是 360×540（截图 1080×1620）**。
- 已生成过的旧保修卡不重做：重新生成才会印上新条款。

## Capabilities

- **New**：`merchant-warranty` —— 卡面内容口径（印什么、不印什么）

> 注：`merchant-warranty` 的基线仍在未归档的 `merchant-warranty-card` change 里，不在 `openspec/specs/`，故本 change 以 ADDED 增量给出；归档时并入同一份 spec。

## Impact

- 代码：`app/lib/features/warranty/warranty_card_view.dart`（条款常量与排版）、相关测试
- 资源 / 依赖 / 数据库：**都不动**（不新增资源、不改表、不升 `schemaVersion`）
- 同步：无协议变更（条款是渲染出来的图，不是字段）

## 非目标

- 不改卡面尺寸（用户明确要求「卡片不变」）
- 不动二维码、商家保修起止、店铺 logo、三条店内条款以外的任何区块
- 不做「旧卡自动重生成」：已存的图不会被覆盖，避免用户手上的凭证突然变样
- 不把条款做成可配置文本（先把这次对完，再谈后台可编辑）
