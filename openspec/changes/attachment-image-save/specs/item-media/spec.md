# Spec Delta

## ADDED Requirements

### Requirement: 附件图片可保存到本地

用户查看商品图片时 SHALL 能把该附件保存到本机。保存 MUST 写入**原图字节**（不是缩略图），并 MUST 通过系统「另存为」对话框由用户选择目标位置；MUST NOT 未经询问就写进某个固定目录。

#### Scenario: 在大图里保存

- **WHEN** 用户点开某张图片的大图并点击「保存」
- **THEN** 弹出系统「另存为」对话框，文件名预填 `ggjb-<商品名前 10 字>-<yyyyMMdd-HHmmss>.<扩展名>`
- **AND** 用户确认后，目标位置出现一张图片，其字节与库中该附件的原图字节一致
- **AND** 界面提示保存成功

#### Scenario: 取消保存

- **WHEN** 用户在「另存为」对话框里取消
- **THEN** 不写入任何文件
- **AND** 界面不出现错误提示

#### Scenario: 图片内容为空时不提供保存

- **WHEN** 该附件的原图字节为零长度
- **THEN** 该图不提供「保存」入口
- **AND** 大图位置显示「无预览」一类的说明

### Requirement: 保存失败给出可读提示

保存失败时 SHALL 用一句话说明「保存失败」，MUST NOT 静默失败，也 MUST NOT 把异常原文或堆栈直接显示给用户。

#### Scenario: 目标位置不可写

- **WHEN** 用户在只读目录或已被占用的路径上确认保存
- **THEN** 界面提示「保存失败」
- **AND** 大图弹窗保持打开，用户可重试

### Requirement: 保存文件名安全

预填文件名 SHALL 剔除路径分隔符（`/` `\`）与 Windows 保留字符（`: * ? " < > |`），并把商品名为空或全是非法字符的情况回退为「图片」；MUST NOT 因文件名非法导致保存失败。

#### Scenario: 商品名含非法字符

- **WHEN** 商品标题为 `A/B:C*?` 且用户保存其图片
- **THEN** 预填文件名不含 `/` `:` `*` `?` 等字符
- **AND** 文件名仍以 `ggjb-` 开头、以正确扩展名结尾

#### Scenario: 扩展名跟随图片类型

- **WHEN** 附件 `mime` 为 `image/jpeg`
- **THEN** 预填文件名的扩展名为 `.jpg`
- **WHEN** 附件 `mime` 为 `image/png` 或未知
- **THEN** 预填文件名的扩展名为 `.png`
