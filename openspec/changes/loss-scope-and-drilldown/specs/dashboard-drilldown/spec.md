# Spec Delta

## ADDED Requirements

### Requirement: 了结亏损卡可下钻到亏损明细

看板上的「了结亏损」指标卡 SHALL 可点击，点击后打开明细列表页，并只显示**单笔利润小于 0** 的商品；明细的组成 MUST 与亏损口径一致（涵盖已卖出、已到账、已退货、已报废四种状态）。

#### Scenario: 点开了结亏损

- **WHEN** 用户在看看板并点击「了结亏损」
- **THEN** 打开明细列表页，只列出单笔利润为负的商品
- **AND** 赚钱的单与在库商品都不出现

#### Scenario: 明细沿看板当前时间段

- **WHEN** 看板筛选为某个时间段（非「全部时间」）
- **AND** 用户点击「了结亏损」
- **THEN** 明细列表沿用该时间段与日期字段

#### Scenario: 没有亏损单时不出现空列表错误

- **WHEN** 当前时间段内没有任何亏损单
- **AND** 用户点击「了结亏损」
- **THEN** 列表显示「没有符合条件的记录」一类的空态
- **AND** 不报错、不崩溃

### Requirement: 亏损卡数字与下钻后的条目数一致

「了结亏损」卡上的「N 单」SHALL 与下钻列表的条目数相等；两者不一致即视为缺陷。

#### Scenario: 单数等于列表条数

- **WHEN** 看板显示「了结亏损 ¥−1200 · 3 单亏钱」
- **AND** 用户点击该卡
- **THEN** 列表恰好显示 3 条商品
- **AND** 这三条的亏损金额相加等于 −1200

### Requirement: 亏损卡明确标注口径

「了结亏损」卡 SHALL 在界面上说明亏损包含哪些来源（贱卖差价、退货与报废全额计亏），使读者不必看文档就知道这张卡统计的是什么。

#### Scenario: 卡片说明文字

- **WHEN** 用户在看板上看「了结亏损」卡
- **THEN** 卡上能看到「N 单亏钱」这样的计数说明
- **AND** 能看到说明文字，指出亏钱包含贱卖与退货、报废

### Requirement: 看板五张指标卡都可下钻到明细

看板「已到手利润」「未到手利润」「待收货款」「了结亏损」「在途占用」五张指标卡 SHALL 全部可点击，点击后打开标题为卡片名、口径与卡片一致的明细列表；点击判定 MUST 由真实指针事件驱动，卡片内部不得有组件抢占点击而使外层回调失效。

#### Scenario: 五张卡逐一点开

- **WHEN** 用户在看板上依次点击五张指标卡中的任意一张
- **THEN** 都打开明细列表页，页面标题为所点卡片的名称
- **AND** 列表按该卡的口径筛选（状态、时间段、是否只看亏损）

#### Scenario: 卡片看得出能点

- **WHEN** 用户看任一可点击的指标卡
- **THEN** 标题行末尾有箭头指示，暗示整卡可点
