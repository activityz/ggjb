# Spec Delta

## Purpose

定义一笔单子赚的钱与亏的钱分别归到哪一栏，以及看板上那几个数字怎么相加才对得上：什么算子「利润」、什么算子「亏损」、两组数字怎样合并成总利润，利润率又该用哪个分子分母。

## ADDED Requirements

### Requirement: 单笔盈亏按利润正负归栏

每一笔已了结的单子 SHALL 依据它自己的单笔利润（卖出价 − 买入价 − 该单全部费用）的正负归入且只归入一栏：利润大于等于 0 的归「利润」，利润小于 0 的归「亏损」。归栏 MUST NOT 由商品状态单独决定。

#### Scenario: 贱卖的单进亏损栏

- **WHEN** 一件 1000 元买入、800 元卖出、无其他费用的商品被标记为「已卖出」
- **THEN** 它的 200 元亏损计入「亏损」合计
- **AND** 这 200 元不出现「已到手利润」或「未到手利润」的合计里

#### Scenario: 赚钱的单进利润栏

- **WHEN** 一件 1000 元买入、1400 元卖出、无其他费用的商品被标记为「已到账」
- **THEN** 它的 400 元利润计入「已到手利润」
- **AND** 这 400 元不计入「亏损」合计

#### Scenario: 不赚不亏的单不算亏损

- **WHEN** 一件商品的卖出价恰好等于买入价加费用，单笔利润为 0
- **THEN** 它计入利润栏（金额为 0）
- **AND** 不计入「亏损」的单数与金额

### Requirement: 亏损覆盖全部四种已了结状态

「亏损」SHALL 同时统计「已卖出」「已到账」「已退货」「已报废」四种状态里的亏损单；其中退货与报废按「买入价 + 该单费用」全额计亏，贱卖按实际差价计亏。同一笔单 MUST NOT 被重复计入。

#### Scenario: 四类亏损混在一起

- **WHEN** 一段时间内有一单贱卖亏 200、一单退货亏 1000、一单报废亏 500
- **THEN** 「亏损」合计为 −1700
- **AND** 亏损单数为 3

#### Scenario: 退货与报废仍按全额计亏

- **WHEN** 一件商品买入 1000、已付运费 50，随后被标记为「已退货」
- **THEN** 该单计入亏损 −1050

### Requirement: 分栏不改变总利润

利润栏合计与亏损栏合计相加 SHALL 等于同一批单子的净额；调整分栏口径 MUST NOT 改变总利润这个数字本身。

#### Scenario: 两栏相加等于净额

- **WHEN** 一批单子里盈利合计 1500、亏损合计 −700
- **THEN** 总利润为 800
- **AND** 与「不区分正负、直接累加每单利润」得到的结果相同

### Requirement: 利润率的分母不随分栏变化

已实现利润率 SHALL 以「已售商品（已卖出 + 已到账）的成本合计」为分母，分子为这批商品的**净额**（盈利减去贱卖亏损）；分母 MUST NOT 因为某单被归入亏损栏就把它的成本剔除。

#### Scenario: 一批货有赚有亏

- **WHEN** 已售两单：一单赚 400、成本 1000；一单亏 200、成本 1000
- **THEN** 分母为 2000
- **AND** 分子为 200
- **AND** 利润率为 10%

#### Scenario: 全部盈利时与旧口径一致

- **WHEN** 已售商品的单笔利润都大于 0
- **THEN** 利润率与「盈利合计 ÷ 已售成本」相同

### Requirement: 未了结的单不进任何一栏

状态为「在库」或「已上架」的商品 SHALL 只计入在途资金占用，MUST NOT 出现在利润合计、亏损合计或利润率的分子分母里。

#### Scenario: 在库商品不影响盈亏

- **WHEN** 库里有三件尚未卖出的商品，买入成本合计 5000
- **THEN** 利润合计为 0、亏损合计为 0
- **AND** 在途占用为 5000
