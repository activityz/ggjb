# Spec Delta

## ADDED Requirements

### Requirement: 详情页展示编辑页可录入的全部商品字段

商品详情页 SHALL 展示编辑页可录入的全部商品字段：名称、品牌、型号、内存规格、颜色、分类、序列号、买入价、买入日期、买入来源、买入时成色、电池健康、厂家保修状态（含「无保修」）、厂家保修起止、状态、卖出价、卖出日期、卖出渠道、卖出时成色、商家保修起止、挂牌价、费用明细、备注。

状态相关的字段（卖出价、卖出日期、卖出渠道、卖出成色、商家保修、挂牌价）MAY 只在对应状态下出现；但**与状态无关的字段（名称、品牌、型号、内存规格、颜色、分类、序列号、买入价、买入日期、买入来源、买入成色、电池健康、厂家保修状态）MUST 始终展示**。

#### Scenario: 分类与序列号在详情页可见

- **WHEN** 一件商品的「分类」为「手机」、「序列号」为 `F2LX1234ABCD`
- **AND** 用户打开该商品的详情页
- **THEN** 页面上能看到「分类」与「手机」
- **AND** 能看到「序列号」与 `F2LX1234ABCD`

#### Scenario: 厂家保修三态都有交代

- **WHEN** 商品的厂家保修状态为「无保修」
- **THEN** 详情页显示「厂家保修：无保修」
- **WHEN** 状态为「已过保」
- **THEN** 显示「厂家保修：已过保」
- **WHEN** 状态为「在保」
- **THEN** 显示厂家保修开始与到期两个日期

#### Scenario: 字段没录时也占一行

- **WHEN** 商品的「分类」为空
- **THEN** 详情页仍显示「分类」这一行，值为「—」
- **AND** 不会因为没填就把整行藏起来

### Requirement: 商品属性按「字段名 + 值」成对展示

品牌、型号、内存规格、颜色、分类、序列号六项 SHALL 以「左侧字段名、右侧值」逐条成行展示，顺序与编辑页一致；MUST NOT 把多个值拼成一行文字展示。

#### Scenario: 四项属性各自成行

- **WHEN** 商品为品牌 `Apple`、型号 `iPhone 13`、内存 `128G`、颜色 `蓝色`
- **THEN** 详情页能分别找到字段名「品牌」「型号」「内存规格」「颜色」
- **AND** 每个字段名右侧分别是 `Apple`、`iPhone 13`、`128G`、`蓝色`
- **AND** 页面上找不到 `Apple · iPhone 13 · 128G · 蓝色` 这种拼接成的一行

#### Scenario: 长值不挤压字段名

- **WHEN** 型号很长（如 `MacBook Pro 14 M3 Pro 18G 512G`）
- **THEN** 字段名仍完整可见，不换行、不被截断
- **AND** 值在自己的区域内完整显示或折行
