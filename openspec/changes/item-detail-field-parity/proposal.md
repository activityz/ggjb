# 提案：详情页字段与编辑页对齐、商品属性按「名 + 值」展示

## 为什么（Why）

详情页是拿货、卖货时最常看的一页，但它的字段和编辑页对不上，也看不清：

- **缺两个字段**：编辑页能录「分类」和「序列号」，详情页**一处都不显示**。序列号还是印在保修卡上的关键号，要核对时在详情页找不到。
- **属性挤成一行小字**：品牌 · 型号 · 内存规格 · 颜色被拼成 `iPhone · 13 · 128G · 蓝色` 这样一行 11px 的灰字，既没有字段名，也不好扫读——四个值混在一起，看不出哪个是内存、哪个是颜色。
- **厂家保修状态少一态**：编辑页有「无保修 / 在保 / 已过保」三态，详情页在「无保修」时什么都不显示，看的人没法区分「没录」和「无保修」。

## 改什么（What Changes）

- 新增「商品属性」卡，用「字段名 + 值」逐条展示：**品牌、型号、内存规格、颜色、分类、序列号**，缺失值显示「—」。顺序与编辑页一致。
- **删掉**标题下那行拼接小字（`品牌 · 型号 · 内存 · 颜色`）。
- 厂家保修补上「无保修」一态：状态为 `none` 时显示一行「厂家保修：无保修」；「在保」仍显示起止日，「已过保」仍显示「已过保」。
- 其余区块的**顺序与内容都不动**（利润卡、费用明细、时间与渠道、图片、备注、保修卡、改状态）。

## Capabilities

- **New**：`item-detail` —— 详情页展示哪些字段、以什么形式展示

## Impact

- 代码：`app/lib/features/item_detail/item_detail_page.dart`（属性卡、删除拼接行、厂家保修状态）、新增测试
- 数据库 / 同步 / 依赖：**都不动**（`category`、`serial` 早就在 `items` 表里，只是没展示）
- Excel：不涉及

## 非目标

- 不整页按编辑页分组重排（现状是「财务主线在前、属性在后」的刻意设计，重排会打乱常用动线）
- 不改编辑页
- 不把属性做成可编辑（详情页只读，改资料仍走编辑页）
- 不动利润卡、费用、图片、保修卡、改状态任何一块
