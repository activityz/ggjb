# 提案：规格改名、详情页文字可选中复制、补图片删除入口

## 为什么（Why）

三个用得上的小问题，都出在详情页：

1. **「内存规格」这个名字太长**：它不只装内存，平板/显卡等品类填的是容量，叫「规格」更贴切，也省地方。
2. **详情页的值复制不了**：序列号、型号这类东西经常要发给别人（发给买家、贴到闲鱼），现在只能靠手抄或截图。但页面已经够挤，不想再加一排复制按钮。
3. **图片删不掉（看起来）**：删除功能其实一直在——长按图片格子会弹确认框——但页面上没有任何提示，用户找不到，以为存进去就删不了了。

## 改什么（What Changes）

- **字段名**：编辑页标签「内存规格」→「规格」；详情页属性行同改；字典分类名同步改（`DictSeeds` 的 storage 组标签）。Excel 表头本来就是「内存」，不受影响。
- **文字可选中**：详情页正文用 `SelectionArea` 包一层，所有值都能长按/拖选复制 —— **不加任何复制按钮**，也不改现有的 `Text` 结构（选择不是通过替换成 `SelectableText` 实现的，行内的点击、长按删除等语义保持原样）。
- **图片删除入口**：大图弹窗里补一个「删除」按钮（走现有的确认流程），长按格子的老路保留。

## Capabilities

- **Modified**：`item-detail` —— 详情页字段名称、文字可选、图片删除入口

> 注：`item-detail` 的基线在未归档的 `item-detail-field-parity` change 里，不在 `openspec/specs/`，故本 change 以 ADDED 增量给出。

## Impact

- 代码：`app/lib/features/item_detail/item_detail_page.dart`（`SelectionArea`、大图删除按钮、属性行标签）、`app/lib/features/item_edit/item_edit_page.dart`（标签）、`app/lib/domain/dict_seeds.dart`（分类名）
- 数据库 / 同步 / 依赖：**都不动**（分类名是常量，不入库）
- 测试：`detail_field_parity_test.dart` 里的「内存规格」断言跟着改；新增选择与删除的用例

## 非目标

- 不做「点一下就复制」的快捷动作（用户明确不要复制按钮，也不额外引入点击复制的隐性手势）
- 不改 Excel 表头（本来就是「内存」）
- 不动图片的添加流程
- 不做批量删除图片
