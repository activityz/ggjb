# Spec Delta

## ADDED Requirements

### Requirement: 字段名统一叫「规格」

编辑页与详情页里，原来叫「内存规格」的那一项 SHALL 改名为「规格」；字典分类名也 MUST 同步改名。MUST NOT 在界面上再出现「内存规格」。

#### Scenario: 详情页与编辑页都显示「规格」

- **WHEN** 用户打开商品详情页
- **THEN** 属性区里能找到「规格」这一行
- **AND** 找不到「内存规格」
- **WHEN** 用户打开编辑页
- **THEN** 输入框标签是「规格」

### Requirement: 详情页的文字可选中复制

商品详情页的所有文字 SHALL 支持选中复制（长按选中、拖选、快捷键复制），且 MUST NOT 为此新增任何复制按钮或复制图标。启用选择 MUST NOT 改变原有交互：行内点击、长按等其他手势保持可用。

#### Scenario: 值能选中

- **WHEN** 用户在详情页长按或拖选一个值（如序列号）
- **THEN** 该文字被选中，可复制到剪贴板

#### Scenario: 没有复制按钮

- **WHEN** 用户看详情页
- **THEN** 页面上找不到「复制」按钮或复制图标
- **AND** 每一行的布局与改前一致（没有为了复制多出一列）

### Requirement: 大图里能删除图片

图片大图弹窗 SHALL 提供一个删除入口；点击后 MUST 先确认，确认后该图片从库中移除并从图片区消失。原有的「长按图片格子删除」MUST 保留。

#### Scenario: 从大图删除

- **WHEN** 用户点开一张图片的大图，点「删除」并在确认框里确认
- **THEN** 弹窗关闭，图片区里不再有这张图

#### Scenario: 取消不删

- **WHEN** 用户点「删除」后在确认框里取消
- **THEN** 图片仍然在
- **AND** 大图弹窗保持打开

#### Scenario: 长按删除仍然可用

- **WHEN** 用户长按图片格子
- **THEN** 仍弹出删除确认框（与改前一致）
