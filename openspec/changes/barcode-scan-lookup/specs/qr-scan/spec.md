# Spec Delta

## Purpose

让每一笔交易记录拥有一张能打在 40×30mm 热敏标签上的二维码：码值即记录主键，扫码即可定位到该记录并进入只读详情，编辑保存后二维码内容保持不变。

## ADDED Requirements

### Requirement: 每笔记录可生成自己的二维码

系统 SHALL 允许用户对任意一条未删除的记录生成二维码，二维码内容 MUST 为该记录的主键标识，且 MUST NOT 随记录的字段修改而变化。二维码展示 MUST 同时给出可被扫码设备识别的图形与明文码值，且 MUST 为白底深色码（不随应用主题反色）。

#### Scenario: 在详情页生成二维码

- **WHEN** 用户在一条记录的详情页触发「二维码」动作
- **THEN** 界面展示该记录的二维码与明文码值
- **AND** 明文码值等于该记录的主键标识

#### Scenario: 同一记录两次生成的二维码一致

- **WHEN** 用户对同一条记录先后两次生成二维码
- **THEN** 两次得到的明文码值完全相同

#### Scenario: 编辑并保存后二维码不变

- **WHEN** 用户编辑该记录的标题、价格或任一其他字段并保存，随后再次生成二维码
- **THEN** 明文码值与编辑前完全相同

#### Scenario: 深色主题下仍可扫

- **WHEN** 应用处于深色主题，用户打开二维码弹窗
- **THEN** 二维码图形保持白底深色码，不跟随主题反色

### Requirement: 二维码可导出为图片

系统 SHALL 支持把当前展示的二维码导出为 PNG 图片，图片 MUST 同时包含二维码图形与明文码值，且 MUST 能打印在 40×30mm 的标签上。导出 MUST NOT 修改任何记录数据。

#### Scenario: 导出成功

- **WHEN** 用户在二维码弹窗中触发「导出 PNG」
- **THEN** 生成一个 PNG 文件并通过系统分享/保存通路交付给用户
- **AND** 文件内容非空且可被图片查看器打开

#### Scenario: 导出失败

- **WHEN** PNG 生成或分享通路报错
- **THEN** 界面提示导出失败
- **AND** 应用不崩溃，记录数据不受影响

### Requirement: 扫码定位到记录

在具备摄像头扫码能力的平台上，系统 SHALL 提供扫码入口；识别到的内容经格式校验后 MUST 定位到唯一一条未删除记录并打开其详情页。无法定位时 MUST 明确告知用户且停留在当前界面。

#### Scenario: 扫到本应用生成的二维码

- **WHEN** 用户扫码，识别到的明文码值是一条存在且未删除记录的主键
- **THEN** 打开该记录的详情页
- **AND** 详情页处于只读展示状态

#### Scenario: 码值格式不合法

- **WHEN** 识别到的内容不符合记录主键的格式
- **THEN** 提示「没找到这一笔」
- **AND** 不跳转，停留在扫码入口所在界面

#### Scenario: 码值合法但记录已删除

- **WHEN** 识别到的码值格式合法，但对应记录已被删除
- **THEN** 提示「没找到这一笔」
- **AND** 不跳转

#### Scenario: 用户取消扫码

- **WHEN** 用户在扫码界面返回或取消
- **THEN** 不发生任何跳转，也不产生提示

### Requirement: 扫码入口的平台可用性

扫码入口 MUST 只在具备摄像头扫码能力的平台出现；不具备该能力的平台 MUST NOT 展示该入口，且 MUST NOT 因缺少该能力而报错或影响其他功能。

#### Scenario: Android 端

- **WHEN** 应用在 Android 上启动
- **THEN** 全局顶栏出现扫码入口

#### Scenario: Windows 端

- **WHEN** 应用在 Windows 上启动
- **THEN** 全局顶栏不出现扫码入口
- **AND** 同步、刷新、看板、明细、设置等功能表现与本次改动前一致

### Requirement: 扫码进入后默认只读、可编辑

扫码进入的详情页 MUST 以只读形式展示数据；用户 MUST 能主动进入编辑界面修改并保存，保存后返回详情页 MUST 展示最新数据并恢复只读展示。

#### Scenario: 扫码后编辑再保存

- **WHEN** 用户扫码进入某记录详情，点击编辑，修改标题后保存
- **THEN** 详情页显示修改后的标题
- **AND** 详情页仍为只读展示，未进入可编辑状态

### Requirement: 连续识别同一码只触发一次

扫码界面在短时间内连续识别到同一码值时 MUST 只触发一次定位与跳转，MUST NOT 因摄像头多帧重复识别而重复打开页面或重复提示。

#### Scenario: 摄像头连续多帧识别到同一码

- **WHEN** 取景界面在连续多帧中都识别到同一码值
- **THEN** 只执行一次定位与跳转
