# Spec Delta

## ADDED Requirements

### Requirement: 列表页可直接出码

明细列表的每一条记录 MUST 提供自己的二维码入口，点击后打开该条记录的二维码弹窗（与详情页是同一个弹窗）。该入口 MUST NOT 影响整卡点击进入详情的既有行为。

#### Scenario: 从列表打开某条记录的二维码

- **WHEN** 用户在明细列表点击某条记录的二维码按钮
- **THEN** 打开该条记录的二维码弹窗
- **AND** 弹窗内容对应该条记录，而不是当前被选中的其他记录

#### Scenario: 点整卡仍然进详情

- **WHEN** 用户点击卡片上二维码按钮以外的区域
- **THEN** 仍然进入该记录的详情页
- **AND** 不弹出二维码

#### Scenario: 列表页二维码弹窗的标题

- **WHEN** 从列表打开某条记录的二维码弹窗
- **THEN** 弹窗中显示该条记录的标题，便于在连续贴标签时确认没拿错
