# 计划：视觉重构（深色玻璃拟态 + 光影动效 + 粒子）

> 需求确认于 m01409。用户已确认：
> ① 方向 = **深色数据风 + 玻璃拟态**（非液玻、非极简、非赛博）；
> ② 粒子 = **看板背景常驻 + 进钱瞬间爆发 + 下拉刷新也加**；
> ③ 动效 = **全上**，含视差与自定义转场；
> ④ 允许引入 `flutter_animate`。
> ⑤ **m01414 追加：效果做到最好，暂不考虑性能问题。**
>
> 状态：**待批准**。

## 目标确认

把当前「默认 Material 3」的界面升级成有明确视觉语言的产品：深色底 + 磨砂玻璃层 + 渐变光影，
关键金额有滚动动效，进钱时有粒子反馈，整体追求「第一眼惊艳、第一百次还耐看」。

**「效果优先」的准确含义**（m01414）：不为省电而阉割视觉，粒子密度、模糊层数、动画层次按「好看」定，
不按「能跑 60fps」定。保留一个「省电模式」开关备用于老设备，但**默认全开**。

**唯一的非性能约束**——品味底线：深色 + 玻璃 + 粒子三者叠加极易变成廉价炫光。
判断标准是「安静但有质感」：粒子透明度压低、发光只给金额不给边框、模糊只做层次不做过曝。

范围边界：
- 只改表现层（`lib/app/theme.dart` + `lib/ui/` + 5 个页面的布局装饰），**不动数据层、不动算钱逻辑**。
- 除 `flutter_animate` 外不引入别的依赖；粒子与模糊全部手写 `CustomPainter`。
- 保留亮色主题（深色为主、亮色为副），跟随系统。

## 视觉基准

**色板**（深色主题）

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面底 | `#0A0E14` → `#121820` 对角渐变 | 纯黑太死，带一点蓝 |
| 玻璃卡底 | `#FFFFFF` @ 6% | 叠在渐变上才有层次 |
| 玻璃描边 | `#FFFFFF` @ 12% → 3% 线性渐变 | 左上亮、右下暗，模拟受光 |
| 主强调 | `#5EEAD4` | 青绿，暗底上才跳得出来 |
| 利润正 | `#34D399` | |
| 利润负 | `#FB7185` | |
| 待收款/警示 | `#FBBF24` | |
| 正文 / 次级 | `#E6EDF3` / `#8B98A5` | |

**字体纪律**：所有金额文字必须 `fontFeatures: [FontFeature.tabularFigures()]`，
否则数字滚动时字宽跳变、整行抖动。

**版面纪律**（堆动效不能代替基本功）：
- 8pt 栅格：所有间距取 4 的倍数，卡片内边距统一 16/20。
- 层级只靠三件事区分：模糊深度、描边亮度、字号字重。不靠彩色边框。
- 一屏最多两个视觉焦点，剩下的用次级色压下去。

## 效果规格（按 m01414 定，不再以帧率为上限）

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 环境粒子数 | **120** | 带最近邻连线，连线距离阈值 130，透明度随距离线性衰减 |
| 爆发粒子数 | **90 内核 + 外环冲击波** | 一次性，1.4 秒后销毁 |
| 单屏 `BackdropFilter` 层数 | **不限**，按视觉层次需要 | 玻璃卡本身 1 层，顶部栏滚动时另加 1 层 |
| 列表入场动画 | **全部条目**，延迟 45ms 递增，超过 12 条后统一用 12×45ms | 不截断，只封顶延迟 |
| 非当前页 ticker | 仍然 `TickerMode(enabled: false)` | 这不是性能妥协，是逻辑正确性——隐藏的页面不该继续运行动画 |

**保留降级开关**：`省电模式`默认**关闭**，开启后 → 环境粒子不创建、连线关闭、模糊改纯色、
视差关闭、入场动画减为仅淡入。给老设备留一条退路，不默认阉割。

## 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 深色 + 玻璃 + 粒子叠加变「廉价炫光」 | 天天看会腻 | 粒子透明度 0.06~0.14；连线透明度 ≤0.08；发光只给金额 |
| 120 粒子 + 连线在中低端机上掉帧 | 滑动不跟手 | 已按用户要求不设上限，但**保留省电开关**；实现时用 `RepaintBoundary` 把粒子层与列表隔开，避免整页重绘 |
| 自定义转场与 `Hero` 冲突出现双动画 | 转场闪一下 | 详情页路由关闭默认转场，只留 `Hero` |
| 滚动驱动 `sigma` 每帧重建 `BackdropFilter` | 可能 jank | 用 `ValueListenableBuilder` 只重建模糊层，不重建内容 |
| 0002/0003 也会改页面文件 | 合并冲突 | **执行顺序：0003 → 0002 → 0004** |
