# 计划：字典化（品牌 / 机型 / 内存 / 颜色 / 分类 / 来源 / 渠道 / 成色）

> 需求确认于 m01356。用户已确认：
> ① 8 类字段全部进字典（不止品牌/型号/内存/颜色）；② 开发阶段无老数据，不需要做数据回填。
>
> 状态：**待批准**。批准前不动代码。

## 目标确认

把商品录入涉及的全部「可枚举字段」收敛到一张字典表，录入页从手打改成「可手输的选择器」，
字典项可增删改并由用户自己维护，且随两端同步。

范围边界：
- 只做字典与录入；不改利润口径、不改同步协议。
- 商品表存**文本快照**（选中的 label），字典改名不回写历史单；机型通过 `parent_id` 绑品牌。
- 不引入新依赖。
